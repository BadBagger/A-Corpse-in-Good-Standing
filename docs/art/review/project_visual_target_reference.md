# Project Visual Target Reference

Image: `docs/art/review/project_visual_target_mockup_v1.png`

Status: reference only. This is not final room art, not a runtime background, not a sprite source, and not palette-gate proof.

## Use It For

- Overall mood and density.
- Side-view point-and-click framing.
- Wet black Corvin silhouette.
- Leviathan ribcage harbor architecture.
- Amber living warmth versus absinthe wrong-light.
- Compact bottom verb and inventory UI direction.

## Do Not Use It For

- Final background plates.
- Character animation frames.
- Hotspot-accurate room layout.
- Palette conformance proof.
- Godot runtime imports.
- Replacing Meshy or Blender source work.

## Production Notes

Corvin is a little too three-quarter here. The actual animation sheets should keep him stricter side-on because this is mostly a side-view adventure game.

The UI is useful for density and mood, but the text and labels are not production UI. The shipped interface still needs Godot/Popochiu implementation and readability testing.

Final game art still follows:

`Meshy helper geometry / Blender greybox -> ink-wash render pass -> paintover -> Godot 2D room with separate prop and hotspot layers`

## Prompt Used

Create a 16:9 gameplay mockup of A Corpse in Good Standing as a side-view point-and-click adventure. Isla Mordida harbor at night is built into the ribcage of a beached leviathan. Corvin Vale stands in side profile in a wet black coat, dripping, grey at the temples, wrong-shouldered, with salt at the knuckles. Use ink-and-wash noir over a 32-bit-era adventure-game screenshot feel. Keep the locked palette: bone paper white, wet black, harbor slate, absinthe green, whale-oil amber, no arterial red. Add a compact bottom verb and inventory UI. Keep it hard-R but non-explicit, with no gore, no nudity, no child character, no watermark.
